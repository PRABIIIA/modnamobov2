# Realm Legends (Fabric 1.20.1)

* **90 мобов** — по 30 в Обычном мире, Незере и Энде (спавнятся естественно, есть яйца призыва).
* **6 боссов** (2 на мир) с полосой здоровья, яростью на 50% HP и призывом прислужников.
  После смерти оставляют сундуки: Обычный / Редкий / Эпический / Легендарный.
* **Легендарная экипировка** (3 комплекта × 4 брони + меч, топор, кирка, лопата, мотыга):
  полёт, ночное зрение, бонусы комплекта и особые эффекты оружия. Предметы имеют 3D-модели.

## Сборка
Локально: `gradle build` (Gradle 8.8+, JDK 17) → `build/libs/realmlegends-1.0.0.jar`.

GitHub: залейте проект в репозиторий — Actions (`.github/workflows/build.yml`) соберёт jar при каждом push
(Actions → запуск → Artifacts). Тег `v1.0.1` создаст GitHub Release с jar.

## Правка контента
`python3 tools/generate.py` (нужен Pillow) пересоздаёт MobDefs.java, языки, лут-таблицы, модели и текстуры.
Новый моб = одна строка в `MOBS_RAW`.

Проверка в игре: `/give @s realmlegends:void_sword`, `/summon realmlegends:nulhar`.
